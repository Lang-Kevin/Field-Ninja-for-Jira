# Storage v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shard `chrome.storage.sync` prefs into one item per `host:projectKey`, migrate v3 → v4 once in the SW, prune dead local caches, surface quota errors/usage in popup + options, and add Export/Import and Copy-to in options.

**Architecture:** `src/types/prefs.ts` stays the only owner of key formats; `src/lib/storage-service.ts` stays the only `chrome.storage` gateway and keeps the public `PrefsStore` shape by assembling it from shards. A new pure module `src/lib/export-schema.ts` validates import files (trust boundary, HR-21). The SW runs migrate → prune → dropLegacy → reinject; popup/options only consume storage-service.

**Tech Stack:** TypeScript 5.4, esbuild (Chrome + Firefox targets), Vitest 1.6 + happy-dom 14 (unit), Puppeteer (integration), MV3.

**Spec:** `docs/superpowers/specs/2026-10-08-storage-v4-design.md` (approved). Section refs below (`§n`) point into it.

## Global Constraints

- Sync key per scope: `jiraFieldVisibility:v4:${host}:${projectKey}` → `PrefShard = Record<issueTypeId, string[]>` (deduped, non-empty; empty shard ⇒ `sync.remove(shardKey)`).
- `jiraFieldVisibility:v3` is read only by `migrateV3ToV4` (full read) and `pruneLocalCaches` (existence check only), then removed after the v4 `set` resolved.
- `jiraFieldVisibility:activations:v1` and `jiraFieldVisibility:settings:v1` formats unchanged; `…:v1`/`…:v2` prefs keys still dropped, never read (HR-3).
- Quota: 8 KB per item (`QUOTA_BYTES_PER_ITEM ?? 8192`), 100 KB total (`QUOTA_BYTES ?? 102400`); byte count = Σ utf8(key) + utf8(JSON.stringify(value)); no `getBytesInUse`.
- Import file limit: `file.size ≤ 256 KB` (262144 B), checked before reading.
- HR-1: no new content-script UI, no DOM write outside `render()`; content keeps `console.error('[jfv] …')` only.
- HR-4: prefs writes (`toggleField`, `setHiddenFields`, `clearPref`, `clearPrefs`, `writeBuckets`) go through `enqueueWrite`; `mergeActivations` uses `activationsWriteChain`; `saveSettings` keeps `settingsWriteChain`; `migrateV3ToV4` hangs on no chain (SW only).
- HR-5: no `chrome.storage.*` outside `storage-service.ts` (content-entry local caches excepted); `src/lib/export-schema.ts` contains no `chrome.*`.
- HR-6: every bucket write passes `isWritableScope(host, projectKey, issueTypeId)` or is skipped.
- HR-16: `clearPrefs()` removes all `jiraFieldVisibility:v4:*` shards; activations + settings stay.
- HR-17: no new permissions — export = `Blob` + `<a download>`, no `downloads` permission, no manifest change.
- HR-20: `GET_FIELDS` stays the only message type; no new message.
- HR-3 (reworded, T11): no v1/v2 migration; exactly one v3→v4 migration, fill-missing, one `set`, `remove(v3)` only after it resolved, idempotent, SW only, before `reinjectContentScript`.
- HR-21 (new, T11): import is a trust boundary — full `validateExport()`, all-or-nothing, quota precheck before any write, merge = file wins per issue-type bucket.
- Public API kept: `loadPrefs(): Promise<PrefsStore>`, `getPref`, `toggleField(): Promise<PrefsStore>`, `setHiddenFields`, `clearPref`, `clearPrefs` — content/ui-overlay compile without edits.
- Commits: `git commit -F <msgfile>`; message ends with trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Write the msg file into the session scratchpad, never into the repo.
- Parallel tasks share one working tree. A task's Step 4 runs only its **own** test files; for `npm run typecheck`, errors inside a sibling task's files (same wave, possibly mid-edit) are tolerated, any error in the task's own files is a FAIL. Full-suite proof happens at the wave gate (below). Integration files need a real Puppeteer browser + a fresh `dist/`; they run only at wave gates W2+ and in T11.

```ts
/** v4: one sync item per host+project scope. Value = issueTypeId → hiddenFieldIds (deduped, non-empty). */
export const PREFS_V4_PREFIX = 'jiraFieldVisibility:v4:';
/** v3 single-item store. Read only by migrateV3ToV4 (pruneLocalCaches: existence check). */
export const PREFS_V3_STORAGE_KEY = 'jiraFieldVisibility:v3';

export type PrefShard = Record<string, string[]>;

export function makeShardKey(host: string, projectKey: string): string {
  return `${PREFS_V4_PREFIX}${makeScopeKey(host, projectKey)}`;
}

/** `host:PROJ` → parts. host = hostname (no ':'), project = [A-Z][A-Z0-9_]* — exactly one ':'. */
export function parseScopeKey(scope: string): { host: string; projectKey: string } | null {
  const i = scope.indexOf(':');
  if (i <= 0 || i === scope.length - 1 || scope.indexOf(':', i + 1) !== -1) return null;
  return { host: scope.slice(0, i), projectKey: scope.slice(i + 1) };
}

export function parseShardKey(key: string): { host: string; projectKey: string } | null {
  return key.startsWith(PREFS_V4_PREFIX) ? parseScopeKey(key.slice(PREFS_V4_PREFIX.length)) : null;
}

export const LOCAL_CACHE_PREFIXES = ['jfv-field-labels:v2:', 'jfv-tab-fields:v2:', 'jfv-section-fields:v2:'] as const;

/** `jfv-*:v2:${host}:${project}:${type}` → `${host}:${project}`; anything else → null. */
export function scopeOfLocalCacheKey(key: string): string | null {
  const prefix = LOCAL_CACHE_PREFIXES.find((p) => key.startsWith(p));
  if (!prefix) return null;
  const rest = key.slice(prefix.length);
  const i = rest.indexOf(':');
  const j = rest.indexOf(':', i + 1);
  if (i <= 0 || j <= i + 1 || j === rest.length - 1) return null;
  return rest.slice(0, j);
}

// ponytail: typeof guard — prefs.ts loads in contexts/tests without a `chrome`
// global; Firefox may not expose the constants at all.
export const SYNC_QUOTA = {
  perItem: (typeof chrome !== 'undefined' ? chrome.storage?.sync?.QUOTA_BYTES_PER_ITEM : undefined) ?? 8192,
  total: (typeof chrome !== 'undefined' ? chrome.storage?.sync?.QUOTA_BYTES : undefined) ?? 102400,
};

  if (!(e instanceof StorageQuotaError)) return null;
  if (e.kind === 'rate') return 'Too many changes per minute — try again shortly';

  const scope = e.scope ? parseScopeKey(e.scope) : null;

  if (/QUOTA_BYTES|quota/i.test(msg)) return new StorageQuotaError('total');

  format: typeof EXPORT_FORMAT;
  version: 1;
  exportedAt?: string;
  /** "<host>:<PROJ>" → issueTypeId → hidden field ids */
  prefs: Record<string, Record<string, string[]>>;
  /** "<host>:<PROJ>" scopes */
  activations: string[];
  settings?: Settings;
}

export interface ExportSummary {
  projects: number;
  buckets: number;
  fields: number;
  activations: number;
  hasSettings: boolean;
}

export type ValidateResult =
  | { ok: true; data: ExportFileV1; summary: ExportSummary }
  | { ok: false; error: string };

const SCOPE_RE = /^[a-z0-9-]+(\.[a-z0-9-]+)*:[A-Z][A-Z0-9_]*$/;
// eslint-disable-next-line no-control-regex
const CONTROL_RE = /[\u0000-\u001f\u007f]/;
const FORBIDDEN_KEYS = new Set(['__proto__', 'constructor', 'prototype']);
const TOP_KEYS = new Set(['format', 'version', 'exportedAt', 'prefs', 'activations', 'settings']);
const SETTINGS_KEYS = ['showFieldButtons', 'debugOutline', 'shrinkCover', 'coverHeightPx'];

class Invalid extends Error {}

function fail(path: string, reason: string): never {
  throw new Invalid(`${path}: ${reason}`);
}

function plainObject(v: unknown, path: string): Record<string, unknown> {
  if (typeof v !== 'object' || v === null || Array.isArray(v) || Object.getPrototypeOf(v) !== Object.prototype) {
    fail(path, 'expected an object');
  }
  for (const k of Object.keys(v)) {
    if (FORBIDDEN_KEYS.has(k)) fail(`${path}.${k}`, 'forbidden key');
  }
  return v as Record<string, unknown>;
}

function scopeKey(v: unknown, path: string): string {
  if (typeof v !== 'string' || v.length > 300 || !SCOPE_RE.test(v)) fail(path, 'expected "<host>:<PROJECT>"');
  return v;
}

function fieldIds(v: unknown, path: string): string[] {
  if (!Array.isArray(v)) fail(path, 'expected an array of field ids');
  if (v.length > 500) fail(path, 'more than 500 field ids');
  v.forEach((id, i) => {
    if (typeof id !== 'string' || id.length < 1 || id.length > 200) fail(`${path}[${i}]`, 'expected a 1-200 char string');
  });
  return [...new Set(v as string[])];
}

function settingsOf(v: unknown): Settings {
  const s = plainObject(v, '$.settings');
  const keys = Object.keys(s);
  if (keys.length !== SETTINGS_KEYS.length || !SETTINGS_KEYS.every((k) => Object.hasOwn(s, k))) {
    fail('$.settings', `expected exactly ${SETTINGS_KEYS.join(', ')}`);
  }
  for (const k of ['showFieldButtons', 'debugOutline', 'shrinkCover']) {
    if (typeof s[k] !== 'boolean') fail(`$.settings.${k}`, 'expected a boolean');
  }
  const h = s.coverHeightPx;
  if (typeof h !== 'number' || !Number.isInteger(h) || h < 20 || h > 600) {
    fail('$.settings.coverHeightPx', 'expected an integer 20-600');
  }
  return {
    showFieldButtons: s.showFieldButtons as boolean,
    debugOutline: s.debugOutline as boolean,
    shrinkCover: s.shrinkCover as boolean,
    coverHeightPx: h,
  };
}

export function validateExport(raw: unknown): ValidateResult {
  try {
    const top = plainObject(raw, '$');
    for (const k of Object.keys(top)) {
      if (!TOP_KEYS.has(k)) fail(`$.${k}`, 'unknown key');
    }
    for (const k of ['format', 'version', 'prefs', 'activations']) {
      if (!Object.hasOwn(top, k)) fail(`$.${k}`, 'missing');
    }
    if (top.format !== EXPORT_FORMAT) fail('$.format', `expected "${EXPORT_FORMAT}"`);
    if (top.version !== 1) fail('$.version', 'unsupported version (expected 1)');
    if (top.exportedAt !== undefined && typeof top.exportedAt !== 'string') fail('$.exportedAt', 'expected a string');

    const prefs: ExportFileV1['prefs'] = {};
    let buckets = 0;
    let fields = 0;
    for (const [scope, shardRaw] of Object.entries(plainObject(top.prefs, '$.prefs'))) {
      scopeKey(scope, `$.prefs.${scope}`);
      const shard: Record<string, string[]> = {};
      for (const [type, list] of Object.entries(plainObject(shardRaw, `$.prefs.${scope}`))) {
        const path = `$.prefs.${scope}.${type}`;
        if (type.length < 1 || type.length > 100 || CONTROL_RE.test(type) || !isKnownIssueType(type)) {
          fail(path, 'invalid issue type');
        }
        const ids = fieldIds(list, path);
        if (ids.length === 0) continue; // empty list = skip bucket, not an error
        shard[type] = ids;
        buckets += 1;
        fields += ids.length;
      }
      if (Object.keys(shard).length > 0) prefs[scope] = shard;
    }

    const act = top.activations;
    if (!Array.isArray(act)) fail('$.activations', 'expected an array');
    if (act.length > 512) fail('$.activations', 'more than 512 entries');
    const activations = [...new Set(act.map((s, i) => scopeKey(s, `$.activations[${i}]`)))];

    const settings = top.settings === undefined ? undefined : settingsOf(top.settings);

    const data: ExportFileV1 = { format: EXPORT_FORMAT, version: 1, prefs, activations };
    if (typeof top.exportedAt === 'string') data.exportedAt = top.exportedAt;
    if (settings) data.settings = settings;
    return {
      ok: true,
      data,
      summary: { projects: Object.keys(prefs).length, buckets, fields, activations: activations.length, hasSettings: !!settings },
    };
  } catch (e) {
    if (e instanceof Invalid) return { ok: false, error: e.message };
    throw e;
  }
}
```

const isPlainObject = (v: unknown): v is Record<string, unknown> =>
  typeof v === 'object' && v !== null && !Array.isArray(v);

/**
 * One-time v3 → v4 move (HR-3). SW only, on no write chain (HR-4). Fill-missing
 * (v4 wins per type), quota precheck before any write, ONE set, remove(v3) only
 * after that set resolved. Idempotent: the v3 key's existence is the only marker.
 */
export async function migrateV3ToV4(): Promise<{ migrated: number; skipped: number }> {
  const all = await chrome.storage.sync.get(null);
  const v3 = all[PREFS_V3_STORAGE_KEY];
  if (!isPlainObject(v3)) return { migrated: 0, skipped: 0 };

  const changed: Record<string, PrefShard> = {};
  let migrated = 0;
  let skipped = 0;
  for (const [key, raw] of Object.entries(v3)) {
    // Trust the value fields, never the composite key.
    const { host, projectKey, issueTypeId, hiddenFieldIds: ids } = isPlainObject(raw) ? raw : ({} as Record<string, unknown>);
    if (
      typeof host !== 'string' || !host ||
      typeof projectKey !== 'string' || !projectKey ||
      typeof issueTypeId !== 'string' || !issueTypeId || !isKnownIssueType(issueTypeId) ||
      !Array.isArray(ids) || !ids.every((id) => typeof id === 'string')
    ) {
      skipped += 1;
      console.warn(`[jfv] migrateV3ToV4: skipped malformed v3 entry "${key}"`);
      continue;
    }
    const shardKey = makeShardKey(host, projectKey);
    const shard = changed[shardKey] ?? { ...((all[shardKey] as PrefShard | undefined) ?? {}) };
    if (ids.length === 0 || Object.hasOwn(shard, issueTypeId)) continue; // v4 wins
    shard[issueTypeId] = [...new Set(ids as string[])];
    changed[shardKey] = shard;
    migrated += 1;
  }

  for (const [k, shard] of Object.entries(changed)) checkItem(k, shard);
  // ponytail: total is checked for the moment of the set (v3 still present) —
  // that is what the browser enforces. Ceiling: a nearly full sync area keeps
  // retrying every startup until the user frees space.
  const bytes = usageOf({ ...all, ...changed });
  if (bytes > SYNC_QUOTA.total) throw new StorageQuotaError('total', undefined, bytes, SYNC_QUOTA.total);
  if (migrated > 0) await syncSet(changed);
  await syncRemove(PREFS_V3_STORAGE_KEY);
  return { migrated, skipped };
}

/**
 * Drops local label/tab/section caches whose host:project has neither a
 * non-empty v4 shard nor an activation. No-op while v3 still exists
 * (migration pending). Best effort: logs, never throws.
 */
export async function pruneLocalCaches(): Promise<void> {
  try {
    const all = await chrome.storage.sync.get(null);
    if (PREFS_V3_STORAGE_KEY in all) return;
    const keep = new Set(Object.keys((all[ACTIVATIONS_STORAGE_KEY] as ActivationStore | undefined) ?? {}));
    for (const [k, v] of Object.entries(all)) {
      const scope = parseShardKey(k);
      if (scope && Object.keys(v as PrefShard).length > 0) keep.add(makeScopeKey(scope.host, scope.projectKey));
    }
    const local = await chrome.storage.local.get(null);
    const stale = Object.keys(local).filter((k) => {
      const scope = scopeOfLocalCacheKey(k);
      return scope !== null && !keep.has(scope);
    });
    if (stale.length > 0) await chrome.storage.local.remove(stale);
  } catch (e) {
    console.warn('[jfv] pruneLocalCaches failed', e);
  }
}

/**
 * Bulk prefs write for import ('replace': file wins per bucket) and Copy-to
 * ('union': the target keeps its own ids). In-memory merge, per-item + total
 * precheck, then ONE set — all-or-nothing (HR-21). Buckets failing
 * isWritableScope (HR-6) or ending up empty are skipped.
 */
export function writeBuckets(buckets: Pref[], mode: 'replace' | 'union'): Promise<void> {
  return enqueueWrite(async () => {
    const all = await chrome.storage.sync.get(null);
    const changed: Record<string, PrefShard> = {};
    for (const { host, projectKey, issueTypeId, hiddenFieldIds } of buckets) {
      if (!isWritableScope(host, projectKey, issueTypeId)) continue;
      const key = makeShardKey(host, projectKey);
      const shard = changed[key] ?? { ...((all[key] as PrefShard | undefined) ?? {}) };
      const merged = mode === 'union' ? [...idsOf(shard, issueTypeId), ...hiddenFieldIds] : hiddenFieldIds;
      const ids = [...new Set(merged)];
      if (ids.length === 0) continue;
      shard[issueTypeId] = ids;
      changed[key] = shard;
    }
    if (Object.keys(changed).length === 0) return;
    for (const [k, shard] of Object.entries(changed)) checkItem(k, shard);
    const bytes = usageOf({ ...all, ...changed });
    if (bytes > SYNC_QUOTA.total) throw new StorageQuotaError('total', undefined, bytes, SYNC_QUOTA.total);
    await syncSet(changed);
  });
}

/** Unions scopes into the activations item with one set (import). Malformed scopes are skipped. */
export function mergeActivations(scopes: string[]): Promise<void> {
  const result = activationsWriteChain.then(async () => {
    const valid = scopes.filter((s) => parseScopeKey(s) !== null);
    if (valid.length === 0) return;
    const updated: ActivationStore = { ...(await loadActivations()) };
    for (const s of valid) updated[s] = true;
    await syncSet({ [ACTIVATIONS_STORAGE_KEY]: updated });
  });
  activationsWriteChain = result.catch(() => undefined);
  return result;
}

/** Copy-to targets: v4 buckets ∪ label-cache buckets (types the user has opened), known types only, deduped, sorted. */
export async function listKnownBuckets(): Promise<{ host: string; projectKey: string; issueTypeId: string }[]> {
  const found = new Map<string, { host: string; projectKey: string; issueTypeId: string }>();
  const add = (host: string, projectKey: string, issueTypeId: string): void => {
    if (isKnownIssueType(issueTypeId)) found.set(makePrefKey(host, projectKey, issueTypeId), { host, projectKey, issueTypeId });
  };
  for (const p of Object.values(await loadPrefs())) add(p.host, p.projectKey, p.issueTypeId);
  const labelPrefix = LOCAL_CACHE_PREFIXES[0]; // 'jfv-field-labels:v2:'
  for (const k of Object.keys(await chrome.storage.local.get(null))) {
    const scope = k.startsWith(labelPrefix) ? scopeOfLocalCacheKey(k) : null;
    const parts = scope ? parseScopeKey(scope) : null;
    if (scope && parts) add(parts.host, parts.projectKey, k.slice(labelPrefix.length + scope.length + 1));
  }
  return [...found.keys()].sort((a, c) => a.localeCompare(c)).map((k) => found.get(k)!);
}

/** Export snapshot: non-empty v4 shards, activation scopes, exactly the 4 Settings keys (round-trips through validateExport). */
export async function buildExport(): Promise<ExportFileV1> {
  const all = await chrome.storage.sync.get(null);
  const prefs: ExportFileV1['prefs'] = {};
  for (const [k, v] of Object.entries(all)) {
    const scope = parseShardKey(k);
    if (scope && Object.keys(v as PrefShard).length > 0) prefs[makeScopeKey(scope.host, scope.projectKey)] = v as PrefShard;
  }
  const { showFieldButtons, debugOutline, shrinkCover, coverHeightPx } = await loadSettings();
  return {
    format: EXPORT_FORMAT,
    version: 1,
    exportedAt: new Date().toISOString(),
    prefs,
    activations: Object.keys((all[ACTIVATIONS_STORAGE_KEY] as ActivationStore | undefined) ?? {}),
    settings: { showFieldButtons, debugOutline, shrinkCover, coverHeightPx },
  };
}

/**
 * HR-21 trust boundary: size check before reading, full validateExport,
 * confirm, then all-or-nothing prefs write (quota precheck inside
 * writeBuckets); activations/settings only after prefs landed.

export async function handleImportFile(file: File): Promise<void> {
  showMessage(STORAGE_ERROR_ID, null);
  showMessage(STORAGE_STATUS_ID, null);
  if (file.size > MAX_IMPORT_BYTES) {
    showMessage(STORAGE_ERROR_ID, `Import file too large (${Math.ceil(file.size / 1024)} KB > 256 KB).`);
    return;
  }
  let raw: unknown;
  try {
    raw = JSON.parse(await file.text());
  } catch {
    showMessage(STORAGE_ERROR_ID, 'Import failed: not a valid JSON file.');
    return;
  }
  const result = validateExport(raw);
  if (!result.ok) {
    showMessage(STORAGE_ERROR_ID, `Import failed: ${result.error}`);
    return;
  }
  const { data, summary: s } = result;
  const what = `${s.projects} projects, ${s.buckets} issue types, ${s.fields} hidden fields, ${s.activations} activations${s.hasSettings ? ', settings' : ''}`;
  if (!confirm(`Import ${what}? Matching issue types are overwritten, others kept.`)) return;

  const buckets: Pref[] = Object.entries(data.prefs).flatMap(([scope, shard]) => {
    const { host, projectKey } = parseScopeKey(scope)!; // validateExport guarantees "<host>:<PROJ>"
    return Object.entries(shard).map(([issueTypeId, hiddenFieldIds]) => ({ host, projectKey, issueTypeId, hiddenFieldIds }));
  });
  try {
    await writeBuckets(buckets, 'replace');
  } catch (e) {
    console.warn('[jfv] import failed', e);
    showMessage(STORAGE_ERROR_ID, quotaMessage(e) ?? 'Import failed.');
    return;
  }
  try {
    await mergeActivations(data.activations);
    if (data.settings) await saveSettings(data.settings);
    showMessage(STORAGE_STATUS_ID, `Imported ${what}.`);
  } catch (e) {
    console.warn('[jfv] import activations/settings failed', e);
    showMessage(STORAGE_ERROR_ID, `Prefs imported; activations/settings failed: ${quotaMessage(e) ?? String(e)}`);
  }
  void render(await loadPrefs());
}

async function copyTo(
  src: Pref,
  targets: { host: string; projectKey: string; issueTypeId: string }[]

  if (targets.length === 0) return;
